### 🏛️ System Architecture Principles

* **Multi-Tenant Isolation & Security:** Expert in PostgreSQL Row-Level Security (RLS) vs. Schema-per-Tenant isolation patterns and connection pooling (PgBouncer).
* **Distributed Rate Limiting & Idempotency:** Engineering atomic Redis Sliding Window limiters and distributed locks (`Idempotency-Key` mutex patterns) for zero duplicate side effects.
* **AI Agentic Workflows & System Integrations:** Embedding production LLM capabilities, RAG architectures, Model Context Protocol (MCP) implementations, and custom API pipelines into modern B2B SaaS applications.
